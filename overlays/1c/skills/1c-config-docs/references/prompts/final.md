# Шаблон задания: финальная сборка и приёмка (фаза 8)

Один агент, сильная модель, строгий отчёт с фактическим выводом команд.

```
Финальная сборка и приёмка комплекта документации (docx + схемы archify). Всё написано; ты
собираешь, проверяешь и экспортируешь.

Раскладка: <наборы: каталог, префикс схем, число схем>; содержание `<contentDir>` (+ generated);
PNG `<pngDir>`; скрипты `<scripts>` (config `<cfg>`); archify `<cli>`.

Шаги:
1. Схемы: validate (9/9, 0/0) + check для всех; повторный deliver каждой во временный путь и
   побайтное сравнение с текущим HTML (перезаписанные чужим процессом — пересобрать); visual-check;
   `export-png --force` → exit 0.
2. Синхронизировать сгенерированные таблицы схем в документах 00 с текущими meta схем
   (только эти строки).
3. Вставить `png` во все блоки `diagram`: `node <scripts>/fill-png.mjs --config <cfg> --dry-run`, затем
   без `--dry-run` → exit 0 (скрипт меняет только поле `png` и сам проверяет разбором, что больше ничего
   не изменилось; exit 1 — у блока нет PNG). Здесь же `check-lifecycle.mjs --config <cfg>` → exit 0
   (ошибка = не-статус без пометки риска: исправить схему или отчитаться).
4. Собрать всё в боевые каталоги: build --all и reference → exit 0, без ошибок; предупреждение
   «href target not found» теперь — дефект (исправить или отчитаться).
5. verify-docx по всем docx → exit 0; число картинок = числу блоков diagram; open-check в Word
   (страницы); PDF 3 документов ТОЛЬКО во временный каталог и просмотр 2–3 страниц каждого:
   картинка читаема, таблицы, оглавление, язык подписей соответствует файлу.
6. make-nav → exit 0, 0 битых ссылок.
7. Экспортная копия: `node <scripts>/make-clear.mjs --config <cfg>` (план, ничего не пишет) → затем тот же вызов с `--apply` → exit 0 (index.html, html схем,
   docx; **без документов из `internalDocs`** — index копии перерисован без них; с
   `--include-internal`, только если пользователь попросил их включить; без JSON, README, служебных
   папок, visual-check, PNG; структура каталогов сохранена; скрипт проверяет, что все ссылки (index →
   docx/html, схема ↔ схема, docx → docx/html, набор ↔ набор) разрешаются внутри копии, и сравнивает
   байты). Ссылки docx на исключённые документы — находка: убрать ссылку из содержания или получить
   от пользователя решение (`--allow-excluded-links` / `--include-internal`).
   Просмотр страниц PDF: PyMuPDF (`pip install pymupdf`) или экспорт Word в PNG; PDF — только
   во временный каталог (`opencheck-word.ps1 -OutDir <tmp>`).
8. Не коммитить; не трогать код и worktree.

Отчёт: по шагу — команда, код выхода, ключевые числа; таблица docx | байты | страницы | картинки;
экспортная копия — число файлов, размер, итог проверки ссылок; что не прошло и что сделано.
```
