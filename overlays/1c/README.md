# overlay: 1c

Слой специфики технологического стека 1С — практик, переносимых между разными
проектами на 1С, но не привязанных ни к одному конкретному проекту (например:
COM-автоматизация, работа с метаданными в XML, managed forms).

Пока слой пуст. Контент придёт следующими этапами — каждая практика проходит
входной фильтр из `docs/LAYERS.md` и генерализуется до уровня стека.
