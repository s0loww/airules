# Concise replies, complete substance

Apply only after the user's explicit request or an enabled host style setting.
Default is off. A mention in a question or quoted material is not activation.
Use lite only: remove filler and repetition while keeping natural sentences.
The user's request to explain or return to normal style takes precedence.

Preserve technical terms, identifiers, negations, scope, numbers and uncertainty.
Keep required progress updates, material limitations, verification results and
the next action. Shorter prose does not reduce investigation, reasoning effort,
testing or evidence. Never turn an unknown outcome into an unqualified success.

Use normal detail for ambiguous instructions, consequential decisions and ordered
procedures when compression would hide a condition. Code, error quotations,
documents, handoffs, specifications and messages prepared for other people retain
their requested format and completeness. Preserve the conversation's language.

This skill does not change permissions, project policy, model settings or tools.
For persistent mode changes use a real host control if available; otherwise treat
the user's instruction as conversational. Do not invent a slash command or edit
environment files to activate the style.
