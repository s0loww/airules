# office-export-pdf

Use the verified local Office conversion engine with a fresh project PDF output. Do not overwrite the source. Confirm the output is a readable nonempty PDF, check page count and extracted key text, render representative pages and inspect layout. Spreadsheet export requires recalculation first. Review page breaks and scaling. No cloud converter or OCR is assumed. Report missing fonts or layout differences and which pages were inspected.
