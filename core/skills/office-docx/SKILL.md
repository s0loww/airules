# office-docx

Read the source structure before editing. Use python-docx from the verified host runtime or another available document library. Preserve headings, tables, headers, footers and page setup required by the request. Use styles rather than repeated ad hoc font changes. Keep original inputs and write a fresh DOCX output.

Render through the host local Office engine, inspect representative pages and fix clipping, table overflow and pagination. Text extraction alone does not establish visual correctness. Return the verified artifact with any limitations.
