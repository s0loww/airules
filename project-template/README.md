# project-template: шаблон проектного слоя

Это шаблон, а не контент. Он описывает проектный слой — то, что остаётся в
целевом проекте и **никогда не возвращается в дистрибутив** airules.

К проектному слою относятся:

- машинные пути (расположение баз, окружений, инструментов на конкретной машине);
- имена доменных объектов и доменные шаблоны кода конкретного проекта;
- креды — только через git-ignored `.env`, никогда в отслеживаемых файлах;
- проектная память (накопленный контекст, заметки, история решений).

При установке дистрибутива инсталлятор заполняет проектный слой на стороне
цели, подставляя реальные значения вместо плейсхолдеров. Обратно в дистрибутив
этот слой не попадает: практика возвращается в ядро только после генерализации
(имена, пути, креды → плейсхолдеры) и прохождения входного фильтра из
`docs/LAYERS.md`.
