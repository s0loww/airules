# Переносимые навыки: адаптация для airules

Дата: 2026-11-05. Добавлены пять host-neutral навыков в `core/skills`.
Это заново написанные компактные процедуры, а не копии runtime или полного
регламента сборки-источника. Место установки и доступность определяет target;
код команд, MCP-подключения и пользовательские профили сюда не входят.

## Матрица интеграции

| Навык | Что добавляет | Существующий владелец / граница | Отличия от источника |
|---|---|---|---|
| `handoff` | Доступный по триггеру вход для сборки/приёма передачи контекста | `session-handoff` владеет расположением, именем и resume; `subagent-pipeline` — передачей между этапами | Нет второго каталога `handoffs/`, автоматических slash-команд, специальных ролей/методов или копии доменных гейтов. Контекст не становится разрешением. |
| `skill-maintainer` | Выбор минимального изменения навыка по подтверждённому методу | `case-book` — диагноз по симптому; `decisions-log` — устойчивое решение; правила — у владельца политики | Нет `/evolve`, `/skill-eval`, фиксированного memory backend и самовольного изменения профиля. Изменяется исходник управляемого навыка, не установленная копия. |
| `security-baseline` | Трассировка границы доверия от входа до эффекта и доказуемая находка | Формат/глубину проверки задаёт проект; специализированные проверки адресные | Нет обязательного полного аудита каждой правки, обязательного retry для любых внешних вызовов, авто-ротации ключей, установки сканера или универсального severity floor. |
| `architecture-evolution` | Совместимость, переход данных, сохранение поведения при рефакторинге | Архитектура и pipeline проекта; существующий долг записывается своим владельцем | Нет обязательного нового ревьюера, универсального уровня Medium и спекулятивных extension points без потребителя. Миграция не разрешается самим ревью. |
| `technical-debt` | Текущая стоимость долга, цена задержки, владелец и наблюдаемое условие выхода | Существующий debt/issue/decision register; отдельные security/testing/performance процессы | Возраст, дублирование и temporary-маркер сами по себе не дефект. Нет автоматического блокирования релиза или создания внешних задач. |

Идентификаторы правил служат логическими указателями через индекс активного
проекта. Относительных ссылок из установленного навыка в предполагаемый каталог
правил нет: target может использовать файлы либо встроенный rulepack.

## Входной фильтр

1. Все пять процедур применимы без изменений в разных технологических стеках.
   В них нет команд платформы, типов доменных объектов, конкретных backend,
   модели исполнения субагентов или локальных путей.
2. Проектные условия, источники истины и дополнительные проверки остаются в
   правилах/паспорте проекта. Навык не несёт знания конкретного проекта.
3. Это вызываемые по задаче процедуры, а не новый общий управляющий регламент.
   Их место — `core/skills`, не always-on контракт и не отдельный процесс,
   конкурирующий с существующим pipeline.

Проверена база `out-of-scope`: запрет принудительного reviewer и формулировок
самоперепроверки сохранён. Обычная задача не обязана активировать эти навыки.

## Источники и атрибуция

Аудировался предоставленный пакет `dsh-1c-bundle` версии `0.1.0`:

- `skills/handoff/SKILL.md` и `skills/skill-maintainer/SKILL.md` — материал для
  сопоставления метода. Первый также ссылается на upstream mattpocock/skills;
  canonical `session-handoff` уже содержит эту атрибуцию. Тексты обоих новых
  навыков написаны отдельно под действующую политику airules.
- `skills/review-general-en/{security-baseline,architecture-evolution,technical-debt}/SKILL.md`
  и `skills/review-general-en/NOTICE` — review-подходы источника. Их собственная
  атрибуция указывает `@ifrankwang/openspec-agents 0.133.2`, MIT,
  Copyright (c) 2025 ifrankwang. К каждой из трёх адаптаций приложен исходный
  текст MIT в `NOTICE`.

Эта атрибуция относится к указанным upstream review-материалам; она не объявляет
весь коммерческий пакет источника MIT и не устанавливает права на его runtime.
Исполняемый код, полные исходные инструкции и конфигурация пакета не копировались.
